# weather-app

A weather app with a Google-like UI. This app provides the ability to view the weather right at the user's location. This is achieved through the use of one of Google's Maps APIs called Geolocation which accepts an HTTPS POST request and returns a JSON response with the latitude and longitude of the user's location with respect to the nearest cellphone or WiFi tower.
